## M2T format
Формат совместимости M=markdown и T=Turtle RDF  
Основные правила:
- `#` - в markdown заголовок, а в turtle комментарий. Взаимоисключений нет
- для перевода строки в формате markdown при формировании turtle на конце строки нужно добавлять два пробела
